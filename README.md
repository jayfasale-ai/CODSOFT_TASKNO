# CodSoft Internship Tasks

Repository containing tasks completed during the CodSoft Machine Learning Internship.

### Completed Tasks:
- **Task 1: Movie Genre Classification** — Text classification using TF-IDF feature extraction with Multinomial Naive Bayes and Logistic Regression.
- **Task 2: Credit Card Fraud Detection** — Fraud classification addressing severe class imbalance using SMOTE, Decision Trees, and Random Forest.
- **Task 3: Customer Churn Prediction** — Churn classification using behavioral and demographic customer features evaluated with Logistic Regression, Random Forest, and Gradient Boosting.
